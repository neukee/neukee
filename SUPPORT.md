# Getting help

Neukee is pre-release. Until version 0.1.0 ships, the best way to get involved is to follow the work in [`docs/TASKS.md`](docs/TASKS.md) and report what you find.

| You want to                        | Go here                                                                                                                 |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Report a finding that's wrong      | [False positive form](https://github.com/neukee/neukee/issues/new?template=false-positive.yml)                          |
| Report a breaking change we miss   | [Missing breaking change form](https://github.com/neukee/neukee/issues/new?template=missing-breaking-change.yml)        |
| Report a bug in the scanner or CLI | [Bug report form](https://github.com/neukee/neukee/issues/new?template=bug-report.yml)                                  |
| Report a security issue            | [Private security advisory](https://github.com/neukee/neukee/security/advisories/new), see [`SECURITY.md`](SECURITY.md) |
| Follow updates                     | [LinkedIn](https://www.linkedin.com/company/neukee) · [X](https://x.com/neukee4dev)                                     |

Before opening an issue, search the [existing issues](https://github.com/neukee/neukee/issues?q=is%3Aissue) in case it's already reported. Never paste proprietary code; a minimal reproduction is always enough.
