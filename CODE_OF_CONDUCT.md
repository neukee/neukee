# Code of Conduct

Neukee adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in every project space: issues, pull requests, reviews, discussions and any event or channel that represents the project.

In short: be respectful, assume good intent, critique code rather than people, and accept that maintainers have the final say on what is merged.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the maintainer by direct message to [@neukee4dev on X](https://x.com/neukee4dev). Reports are handled confidentially, and the enforcement guidelines in the Contributor Covenant decide the response.

Security vulnerabilities are not conduct issues. Report them through [`SECURITY.md`](SECURITY.md).
